# 원본 역 데이터
- 출처: 서울 열린 데이터광장 서울시 역사마스터 정보  
- URL: (https://data.seoul.go.kr/dataList/OA-21232/S/1/datasetView.do)  
- 원본 파일명: 서울시 역사마스터 정보.json => station-master.json으로 변경  

## 갱신 방법

1. 같은 데이터셋에서 새로 받아 `station-master.json`을 교체
2. 이 파일의 「받은 날짜」 수정
3. `npx tsx scripts/build-stations.ts` 실행
4. 출력에서 확인
   - 「제외한 노선」에 새 노선이 생겼는지 → 필요하면 `LINES`·`ROUTE_TO_LINE`에 추가
   - 「중복 제거」 목록이 예상과 같은지
   - 「원본에 없는 ROW_OVERRIDES id」 경고가 없는지
   - 호선별 역 수가 크게 바뀌지 않았는지
5. `git diff src/data/stations.json`으로 바뀐 역 확인 후 커밋

## 제외 근거

`build-stations.ts`의 `EXCLUDED_LINES`(노선째)와 `EXCLUDED_STATIONS`(역 단위). 판정에 필요한 남은 시간(barvlDt)을 주지 않거나, 첫 열차를 건너뛰게 되는 역을 뺀다.

### 2026-10-29 실측 (목 15:36–16:13, 서울시 API 847회)

- EXCLUDED_LINES 10개: 1호선, 8호선, 경의중앙선, 수인분당선, 신분당선, 경춘선, 공항철도, 서해선, 신림선, GTX-A.
  1호선 외 9개는 barvlDt가 늘 0. 1호선은 서울교통공사 구간인 종로3가에서도 남은 시간이 있는 열차가 38%뿐이라
  일부만 남기면 먼저 오는 코레일 열차를 판정이 건너뜀 → 통째로 뺌. 위치로 추정하면 ±30초 적중 37%.

### 2026-10-30 실측 (금 16:49–17:49)

- EXCLUDED_LINES에 경강선 추가: 12개 역 모두 아직 안 온 열차의 barvlDt가 0 (5,239행).
- EXCLUDED_STATIONS 서울 밖 42개 역: 3호선 일산선 11, 4호선 과천선 9·안산선 13·진접선 3,
  5호선 하남선 4 + 강일, 7호선 장암. 진접선 3개 역과 장암은 데이터 없음(INFO-200),
  나머지는 barvlDt가 늘 0.
- 서울 경계 역 4개(구파발 3호선, 남태령·사당·총신대입구(이수) 4호선)도 제외: 가장 가까운 열차가
  서울 밖 구간에 있으면 barvlDt가 0이라 첫 열차를 건너뜀 (남태령 상행 100%, 사당 상행 73%).
  사당 2호선·이수 7호선은 남는다.
- 7호선 광명(철산·광명사거리)·부천·인천(까치울~석남) 13개 역은 barvlDt 100%라 남김.
- 예전 EXCLUDED_STATIONS(광명·서동탄·춘천)는 노선째 빠지므로 지움.

### 원본 보정

- 까치산(2519)은 원본에 5호선 행만 있어 2호선 신정지선 종점이 빠져 있었다 → ROW_OVERRIDES로 2호선 추가 (2호선 50 → 51개).
