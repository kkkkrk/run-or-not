# 원본 역 데이터
- 출처: 서울 열린 데이터광장 서울시 역사마스터 정보  
- URL: (https://data.seoul.go.kr/dataList/OA-21232/S/1/datasetView.do)  
- 원본 파일명: 서울시 역사마스터 정보.json => station-master.json으로 변경  

## 갱신 방법

1. 같은 데이터셋에서 새로 받아 `station-master.json`을 교체
2. 이 파일의 「받은 날짜」 수정
3. `npx tsx scripts/build-stations.ts` 실행
4. 출력에서 확인
   - 「제외한 노선」에 새 노선이 생겼는지 → 필요하면 `LINES`·`ROUTE_TO_LINE`에 추가
   - 「중복 제거」 목록이 예상과 같은지
   - 「원본에 없는 ROW_OVERRIDES id」 경고가 없는지
   - 호선별 역 수가 크게 바뀌지 않았는지
   - 「다음 역이 없는 칸」이 16개 그대로인지, 「끝 역이 아닐 수 있는 빈칸」 경고가 없는지 (아래 「다음 역 원본」)
5. `git diff src/data/stations.json`으로 바뀐 역 확인 후 커밋

## 제외 근거

`build-stations.ts`의 `EXCLUDED_LINES`(노선째)와 `EXCLUDED_STATIONS`(역 단위). 판정에 필요한 남은 시간(barvlDt)을 주지 않거나, 첫 열차를 건너뛰게 되는 역을 뺀다.

### 2026-10-29 실측 (목 15:36–16:13, 서울시 API 847회)

- EXCLUDED_LINES 10개: 1호선, 8호선, 경의중앙선, 수인분당선, 신분당선, 경춘선, 공항철도, 서해선, 신림선, GTX-A.
  1호선 외 9개는 barvlDt가 늘 0. 1호선은 서울교통공사 구간인 종로3가에서도 남은 시간이 있는 열차가 38%뿐이라
  일부만 남기면 먼저 오는 코레일 열차를 판정이 건너뜀 → 통째로 뺌. 위치로 추정하면 ±30초 적중 37%.

### 2026-10-30 실측 (금 16:49–17:49)

- EXCLUDED_LINES에 경강선 추가: 12개 역 모두 아직 안 온 열차의 barvlDt가 0 (5,239행).
- EXCLUDED_STATIONS 서울 밖 42개 역: 3호선 일산선 11, 4호선 과천선 9·안산선 13·진접선 3,
  5호선 하남선 4 + 강일, 7호선 장암. 진접선 3개 역과 장암은 데이터 없음(INFO-200),
  나머지는 barvlDt가 늘 0.
- 서울 경계 역 4개(구파발 3호선, 남태령·사당·총신대입구(이수) 4호선)도 제외: 가장 가까운 열차가
  서울 밖 구간에 있으면 barvlDt가 0이라 첫 열차를 건너뜀 (남태령 상행 100%, 사당 상행 73%).
  사당 2호선·이수 7호선은 남는다.
- 7호선 광명(철산·광명사거리)·부천·인천(까치울~석남) 13개 역은 barvlDt 100%라 남김.
- 예전 EXCLUDED_STATIONS(광명·서동탄·춘천)는 노선째 빠지므로 지움.

## 다음 역 원본 (neighbors.json)

역명판 양옆 칸에 쓰는 방향별 다음 역 이름의 원본. `build-stations.ts`가 `stations.json`의 `next`(`up` · `down`, 없으면 `null`)로 옮긴다.

- 출처: 서울시 실시간 지하철 도착정보 API `realtimeStationArrival/ALL` 응답 한 번
- 받은 날짜: 2026-11-16 (파일 시각 16:26)
- 만든 스크립트: `scripts/collect-neighbors.mts` — 역 · 방향마다 처음 본 `trainLineNm`(「도봉산행 - 천왕방면」) 하나를 저장. 키는 `API 역명-subwayId`
- 「○○방면」은 열차가 아니라 (역, 방향)에 고정된 다음 역이다 (픽스처 bonghwasan-6: 봉화산에서 끝나는 열차도 「봉화산행 - 신내방면」). 끝 역에서는 자기 역이 온다 (kkachisan: 「까치산행 - 까치산방면」)

### 다시 받을 때

1. `scripts/collect-neighbors.mts` 실행 (환경 변수 `SEOUL_API_KEY` 필요. 열차가 다니는 시간에)
2. 위 「받은 날짜」 수정
3. `npx tsx scripts/build-stations.ts` 실행 → 「다음 역이 없는 칸」이 16개인지, `!` 경고가 없는지 확인
4. `npx vitest run src/lib/stations.test.ts`, `git diff src/data/stations.json`으로 바뀐 `next` 확인

응답 한 번이라 그 순간 열차가 없던 방향은 빈 배열로 남고, 빈 배열만으로는 끝 역과 구분이 안 된다.
「끝 역이 아닐 수 있는 빈칸」 경고가 뜨면 `NEXT_OVERRIDES`에 다음 역 이름을, 끝 역이 맞으면 `null`을 적는다.
다음 역이 제외된 역인 칸(연신내 3호선 up · 불암산 up · 동작 4호선 down · 상일동 down · 도봉산 up)은 가리켜 줄 이웃이 없어 경고로 못 잡는다 → `src/lib/stations.test.ts`에 고정.

### 예외 근거 (NEXT_OVERRIDES, 2026-11-16)

원본 598칸(299개 역 × up · down)을 역사 ID 순서와 대조했다. 277개 역은 ID가 이웃한 역과 같고,
다른 22개는 2호선 순환 이음매 · 성수/신정/마천 지선 · 응암 순환 · 제외된 이웃이라 ID 순서와 다른 게 정상이다.
원본을 그대로 쓰면 틀리는 칸은 아래 6칸.

| 역 | 방향 | 원본 | 고친 값 | 이유 |
|---|---|---|---|---|
| 까치산 2호선 | down | 빈 배열 | 신정네거리 | 지선 종점에서 신도림 쪽으로 떠나는 열차가 그 순간 없었음 |
| 불암산 4호선 | down | 빈 배열 | 상계 | 위와 같음 |
| 불암산 4호선 | up | 「불암산행 - 불암산방면」 | 별내별가람 | API 노선도가 불암산에서 끝남(진접선은 INFO-200). 진접행은 지나간다 |
| 종합운동장 9호선 | up | 「중앙보훈병원행 - 종합운동장방면 (급행)」 | 삼전 | 급행 행 14칸 중 끝 역이 아닌데 자기 역이 온 곳은 여기뿐 (이유는 모름) |
| 응암 6호선 | up | 「응암순환(상선)행 - 응암순환(상선)방면」 | 역촌 | 새절 쪽에서 와서 순환으로 들어간다 (픽스처 eungam-6) |
| 응암 6호선 | down | 「신내행 - 역촌방면」 | 새절 | 순환을 돌아 새절로 나간다 (픽스처 eungam-6) |

- 응암 순환 구간(역촌 · 불광 · 독바위 · 연신내 · 구산)은 한 방향(down)만 다녀서 up을 `null`로 적어 둠 (빈칸 검사에 「확인함」으로 답한 것)
- 지선이 갈라지는 역은 방향당 이름이 하나라 본선 쪽만 들어간다: 강동 down 길동(마천행은 둔촌동으로 감) · 성수 up 건대입구 · 신도림 up 문래. API도 「마천행 - 길동방면」으로 준다
- 응암 하행 목록에는 지금 응암에 서 있는 열차도 「응암순환(상선) 도착」으로 나오는데 `barvlDt`는 순환을 한 바퀴 돌아 다시 오는 시간이다 (eungam-6: 6309번 840초)
